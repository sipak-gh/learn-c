# References

This file lists the sources behind the facts in this course: the C99 standard, POSIX, the Linux manual
pages, the glibc and musl documentation and source code, the GCC and GNU make manuals, the IRC
specifications that parley follows, and the Ubuntu packaging that sets the compiler's defaults. Use it to
check a claim or to read further.

Each source has two links: **original** (the live page) and **archived** (a snapshot in the Internet
Archive's [Wayback Machine](https://web.archive.org/), in case the original moves or changes). Links into
source files (glibc, musl, Ubuntu packages, Linux and others) point at a fixed release tag or commit, and
their archived copy is in [Software Heritage](https://www.softwareheritage.org/), an archive of public
source code. Compiler and linker messages, program output and measurements shown in the chapters come from
running the course's own code with gcc 11.4.0 on Ubuntu 22.04, glibc 2.35 and musl 1.2.6, and aren't
listed here.
